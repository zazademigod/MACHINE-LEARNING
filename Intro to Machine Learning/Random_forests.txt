RANDOM FORESTS 

The random forest uses many trees, and makes the prediction by averaging the predictions of each component tree.
Generally it has much better predictive acuracy than a single decision tree annd works well with default parameters.

We build a random forest similar to how we build a decision tree model in sckit learn - This time we use the RandomForestRegressor class instead of the DecisionTreeRegressor.
