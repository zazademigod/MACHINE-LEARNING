This lesson is about using model validation to improve the quality of built models

the relevant measure of model quality is predictive accuracy
There are many metrics for summarising model quality, but i'll start with one called Mean Absolute Error

in house prediction for example, the prediction error for each house is:
error = actual-predicted

so if a house cost $250,000 and your model predicted $180,000 the error is $70,000


with MAE we take the absolute value of each error, this converts each error into a positive number. we then take the average of those absolute errors, this is our measure of model quality and can be said in plain text as "on average, our predictions are off by about X"

to calculate the MAE, we first need a model
