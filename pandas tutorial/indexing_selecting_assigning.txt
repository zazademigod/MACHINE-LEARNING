INDEXING IN PANDAS

the indexing we've been using are standard python index ecosystem, pandas has it's own accessor operators, "loc" and "iloc". For more complex operations these are what we're are supposed to be using.

Pandas indexing works in one of two paradigms. The first is index-based selection: his is selecting data based on it's numerical position in the DataFrame. "iloc" follows this paradigm.


to select the first row in a dataframe, the following may be utilised

sample.iloc[0] #this returns the first row

new_file.iloc[:10] #this returns the first 10 rows in the dataframe

Note: in native python indexing and referencing, we move in column first he row next direction, but "iloc" and "loc" do the opposite, row first, column next.

USING ILOC(Index based selection)

to fetch the first 5 rows of the first column in a dataframe, we do 

sample.iloc[:5, 0] #this uses just one squae bracket but seperates the rown and column by comma

to reference some specific indexes in a dataframe we use for example,

sample.iloc[[2, 3, 5, 6, 9]] #This returns the 2nd, 3rd, 5th, 6th, and 9th rows

we can also trim it down to return the first column of each of these rows like this,

sample.iloc[[2, 3, 5, 6, 9], 0] #this returns the first column of each of the indexed rows
