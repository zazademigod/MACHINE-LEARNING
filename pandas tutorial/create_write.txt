	CREATING DATA

In pandas thee are two main objects called DataFrame and and the Series

a dataframe is a table, it contains an array of individual entries, each of which has a certain value. Each entry corrresponds to a row and a column.

example: 
pd.DataFrame({"scale": [12, 6], 'size': [2, 4]})

the above creates a 2 column three rows table (removing index column), header of the columns are scale and size, while the values in the square bracket are the calues in the cells under each column 

to dictate the index, we use the index value
example:

pd.DataFrame({'test': [1, 2, 3], 'test 2': [4, 5, 6], index=['one', 'two', 'three']})

another way is 

pd.DataFrame([[12, 2], [6, 4]}, columns= ["scale", "size"], index = ["hello", "hi"])

	
Series: this is different from the dataframe in the sense that it is a sequence of data, essentially if a dataframe is a table, a series is a list

example: pd.Series[2, 34, 15, 29]

#This gives a list 
0	2
1	34
2	15
3	29
dtype: int64

A series in essence is a single column of a DataFrame, it doesn't havve column names just one overall name that is defined 
example:

pd.Series([2, 34, 25, 29], index= ["first", "second", "third", "fourth"], name = "A random list")

Series and Dataframes are related, and it's safe to think of a dataframe as a group of series sandwiched together


READING DATA FILES

to read a csv file into a dataframe for example we use the read_csv() command 

we can use the shape attribute to check how big the dataframe is, example_file.shape
we can see the first five rows of a dataframe by using the head() command, example_file.head()

when we use the read_csv function, we see that pandas tries to create a new index apart from the one already in the original data, to prevent that and allow it use the original we specify an index_col

ex: 
example_file = pd.read_csv(file_path, index_col=0)

To create a csv file we use the .to_csv method
